
# Automated Tank Level Control System – PLC Programming

## Project Description
This project involves the development and simulation of an automated tank level control system using CODESYS and Factory I/O.

The system supports both automatic and manual operating modes. In automatic mode, the user can select predefined tank level setpoints, and the PLC automatically controls the filling and emptying process to reach the selected level.

## Software and Technologies
- CODESYS
- Factory I/O
- PLC Programming (Ladder Logic)
- HMI Visualization

## Features
- Automatic and manual operating modes
- Digital display of the current tank level
- Manual filling and emptying using Panel buttons
- Selection of predefined tank level setpoints in automatic mode
- Automatic control of the filling and emptying process
- Real-time tank level monitoring

## Learning Objectives
Practical implementation and understanding of:
- PLC programming using Ladder Logic
- Automatic and manual control
- Analog inputs and outputs
- Interlocking
- Signal Scalling
- Process control

## Project Structure
- `CODESYS/` – PLC program and global variables
- `FactoryIO/` – Factory I/O simulation scene
- `Demo/` – Project screenshots and System demonstration
